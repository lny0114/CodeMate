# C 语言练习题库（初学者分级）

> 题目按知识点与难度组织，只给“练习目标 + 提示”，不给完整答案，鼓励学生独立完成。
> 难度标记：★ 入门　★★ 基础　★★★ 进阶小综合。

## 一、变量、输入输出与顺序结构

### 练习 1：个人名片 ★
- 知识点：printf 基本输出、占位符。
- 任务：在屏幕上按固定格式打印自己的姓名、年龄、爱好。
- 提示：注意中文在部分老旧编译器下的编码问题；信息里带引号时要转义。

### 练习 2：两数之和 ★
- 知识点：scanf、int 变量、`%d`。
- 任务：从键盘读入两个整数，输出它们的和。
- 提示：scanf 里的变量记得加 `&`；先不要急着做减法乘法。

### 练习 3：温度转换 ★★
- 知识点：double、`%lf` 输入 / `%f` 输出、公式计算。
- 任务：输入摄氏温度，输出华氏温度（公式可自行查阅），保留两位小数。
- 提示：除以 9 时小心整数除法陷阱，写成 `9.0`；保留两位用 `%.2f`。

### 练习 4：找零计算器 ★★
- 知识点：算术运算、常量 const、取余 `%`。
- 任务：输入商品价格和支付金额，输出应找零的钱数（可扩展为纸币张数）。
- 提示：用整数“分”计算可以避免浮点误差；张数问题用 `/` 和 `%` 配合。

## 二、分支结构

### 练习 5：成绩及格判定 ★
- 知识点：if-else、关系运算。
- 任务：输入一个 0~100 的分数，输出“及格/不及格”。
- 提示：先不考虑非法输入；写完后再想分数 >100 怎么办。

### 练习 6：三个数的最大值 ★★
- 知识点：if、变量打擂台思想。
- 任务：输入三个整数，输出最大值。
- 提示：先假设第一个最大，再依次和后两个比较、更新；不要把三个数六种大小关系全枚举。

### 练习 7：简易计算器 ★★
- 知识点：switch、字符输入、break。
- 任务：输入“数字 运算符 数字”，输出 + - * / 的结果。
- 提示：除法要单独判断除数是否为 0；每个 case 末尾检查 break；运算符用 char 配合 `%c` 读取。

### 练习 8：闰年判断 ★★
- 知识点：逻辑运算符 &&、||、!。
- 任务：输入年份，判断是否为闰年。
- 提示：规则是“能被 4 整除但不能被 100 整除”，或者“能被 400 整除”；先把中文规则翻译成布尔表达式。

### 练习 9：分段函数求值 ★★
- 知识点：else if 链、区间判断。
- 任务：对给定的分段函数，输入 x 输出 y。
- 提示：区间判断注意边界值（等于时归哪一段），并保持各分支互斥。

## 三、循环结构

### 练习 10：1 到 100 求和 ★
- 知识点：for 循环、累加器。
- 任务：计算 1+2+…+100。
- 提示：sum 的初始值必须是 0，且初始化放在循环外；做完再改成求偶数之和。

### 练习 11：猜数字游戏 ★★
- 知识点：while 循环、if 嵌套、随机数 rand。
- 任务：程序“想”一个 1~100 的数，玩家反复猜，提示大了/小了，直到猜对。
- 提示：`rand()` 需要 `#include <stdlib.h>`，用前可 `srand` 设种子；循环终止条件是“猜对”。

### 练习 12：打印九九乘法表 ★★
- 知识点：嵌套 for 循环、格式化输出。
- 任务：输出三角形排布的 9×9 乘法表。
- 提示：外层控制行、内层控制列；内层循环次数和“当前行号”有关；用 `\t` 对齐。

### 练习 13：判断素数 ★★
- 知识点：循环 + 标志变量（打标记）。
- 任务：输入一个正整数，判断是否为素数。
- 提示：设一个标记 `int isPrime = 1;`，一旦发现因子就改成 0 并提前结束循环；注意 1 不是素数。

### 练习 14：求最大公约数 ★★
- 知识点：while、取余运算。
- 任务：输入两个正整数，求最大公约数。
- 提示：可以用“辗转相除法”：反复用大数对小数取余，直到余数为 0；先把算法在纸上走一遍。

### 练习 15：斐波那契数列 ★★
- 知识点：循环中的变量滚动更新。
- 任务：输出前 20 项斐波那契数（1, 1, 2, 3, 5…）。
- 提示：不需要数组，用三个变量“前两项 → 新项 → 滚动”即可；注意 int 到后面可能溢出。

## 四、数组

### 练习 16：成绩统计 ★
- 知识点：一维数组、遍历、累加、求平均。
- 任务：读入 n 个成绩，输出总分、平均分、最高分、最低分。
- 提示：循环一次就可以同时完成求和与最值；max/min 用数组第一个元素初始化。

### 练习 17：数组逆序输出 ★★
- 知识点：下标操作、交换。
- 任务：把一个数组原地逆序后输出。
- 提示：只需交换前一半元素：`a[i]` 和 `a[n-1-i]`；先想清楚循环到哪里停。

### 练习 18：冒泡排序 ★★
- 知识点：嵌套循环、相邻元素比较交换。
- 任务：将 n 个整数从小到大排序。
- 提示：每一轮把当前最大的“冒泡”到末尾；画出一轮中相邻元素的比较过程；边界用 `n-1-轮数`。

### 练习 19：二分查找 ★★★
- 知识点：有序数组、循环、边界维护。
- 任务：在已排序数组中查找某个数，输出位置或“未找到”。
- 提示：维护 left、right、mid 三个下标；每次比较后只改一端；先明确循环条件用 `<` 还是 `<=`。

### 练习 20：矩阵转置 ★★★
- 知识点：二维数组、嵌套循环。
- 任务：输入一个 3×3 矩阵，输出它的转置。
- 提示：转置只需遍历对角线一侧交换 `a[i][j]` 与 `a[j][i]`；注意行列下标别写反。

## 五、字符串与字符

### 练习 21：统计字符个数 ★★
- 知识点：字符数组、'\0'、strlen。
- 任务：输入一行字符，统计字母、数字、空格和其他字符的数量。
- 提示：可以用 `s[i] >= 'a' && s[i] <= 'z'` 这类比较判断范围；循环到 '\0' 结束。

### 练习 22：大小写转换 ★★
- 知识点：字符的 ASCII 本质、字符运算。
- 任务：把字符串中的大写字母转小写、小写转大写，其他字符不变。
- 提示：大写与小写字母 ASCII 码相差固定值，可查阅后用加减实现，也可了解 ctype.h。

### 练习 23：回文判断 ★★
- 知识点：字符串、双下标思想。
- 任务：判断输入的字符串是否为回文（正读反读相同）。
- 提示：两端各放一个下标向中间靠拢，发现不同即可下结论；长度用 strlen，不要把 '\0' 算进去。

## 六、函数

### 练习 24：封装判断素数函数 ★★
- 知识点：函数定义、返回值、复用。
- 任务：写 `int isPrime(int n)`，并在 main 中输出 100 以内所有素数。
- 提示：先让函数在一个数上正确，再考虑被循环反复调用；注意 0 和 1。

### 练习 25：用函数实现数组排序 ★★
- 知识点：数组作函数参数（退化为指针）、额外传长度。
- 任务：把冒泡排序封装成 `void bubbleSort(int a[], int n)`。
- 提示：函数里改数组内容会影响实参（传的是地址），但长度信息必须单独传进去。

### 练习 26：交换两个整数 ★★
- 知识点：值传递 vs 地址传递、指针入门。
- 任务：写函数交换 main 中两个变量的值，并验证确实交换成功。
- 提示：普通参数做不到（值传递只改副本）；形参要写成指针，调用时传 `&x, &y`，函数内用 `*a`、`*b`。

## 七、结构体与简单综合

### 练习 27：学生成绩管理（简化版） ★★★
- 知识点：结构体、数组、函数划分、菜单循环。
- 任务：定义 `struct Student`（学号、姓名、成绩），支持录入 5 名学生、按成绩排序输出、按学号查询。
- 提示：先只做“录入 + 全部输出”跑通，再加排序和查询；比较函数可以专门写一个；不要追求一次写完。

## 练习推荐原则（供 CodeMate 诊断时参考）

1. 学生在某个知识点出错（如 scanf 的 &），优先推荐同知识点的 ★ 题巩固，再推 ★★ 题迁移。
2. 每次最多推荐 1~3 个练习，并说明“做这题能练到什么”。
3. 鼓励学生完成后把新代码再次提交诊断，形成“提交 → 诊断 → 修改 → 再诊断”的陪练闭环。
